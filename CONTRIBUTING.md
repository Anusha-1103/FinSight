# Contributing to FinSight AI

Thank you for contributing to FinSight AI! Please follow these guidelines:

## Code Standards
1. All backend code must pass TypeScript compilation (`npm run build` in `server/`).
2. All frontend code must adhere to the **Warm Editorial Luxury Design System** tokens (`client/src/index.css`).
3. Never use raw synthetic colors or unapproved drop shadows.
4. Ensure all numerical data uses tabular monospace font styling.

## Pull Request Workflow
1. Fork repository and create feature branch (`git checkout -b feature/amazing-feature`).
2. Verify TypeScript build and tests (`npm test` in `server/` and `npm run build` in `client/`).
3. Open Pull Request detailing changes.
